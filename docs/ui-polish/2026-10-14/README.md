## 具体修改

- 八份样式统一为语义颜色变量，覆盖阅读区、对话、输入、菜单、设置、插件、语音和截图面板。
- 工作区选择、会话选中、新建会话采用中性底色；浅色左侧不再使用大面积深蓝或鲜蓝背景。
- 正文与提示的字号、行距、文本对比度以及输入框边界更清晰。主对话与临时对话的输入区底边对齐。
- 320px 窄窗口的工具栏分两行，侧栏位于工具栏下方，外观、布局与设置入口保持可达。原有手动布局继续保留，可在布局设置中选择纵向排列。
- 调整工作栏的可读最小尺寸、选区菜单边界与工作栏设置菜单定位。设置菜单根据实际尺寸定位并随窗口、滚动及内容尺寸变化更新。
- DOM 文档截图背景读取当前文档容器颜色，消除浅色界面截图边缘出现旧深色底的问题。

## 功能与接口边界

`apps/server`、`packages`、前端 API、聊天和设置业务源码未修改。移除新增外观组件的 import 和插入节点后，`App.tsx`、`Workbench.tsx` 与修改前源码一致。新增偏好不写入工作区或会话状态。

原有会话切换、主/临时会话隔离、草稿、逐次文件生成授权、文件版本与引用、文档选区、截图、插件与导出流程均保持原实现。截图辅助函数只调整渲染背景；菜单只调整显示位置与可见范围。
