## 执行裁定与代价

- 在当前专用功能分支实施，复用现有 checkout；代价是源改动出现在当前目录。
- Windows 直接维护执行台账，替代 POSIX 脚本；代价是手工记账。
- 记忆目录使用包含插件身份的哈希；代价是目录名不可读，需通过状态接口查找。
- 第 5 步先接入实际 RunService 消费者，以验证真实流程；代价仅为接线顺序变化。
- OCR 回归明确停用视觉记忆；代价是文本模型/OCR 用户需要停用该插件。Windows 路径比较使用 realpath，代价是测试比较规范路径。原生浏览器截图先排空初帧再隐藏遮罩；代价最多额外一帧延迟，静态注入流只读取一帧。浏览器测试串行执行，避免共享报告目录冲突；代价是没有并行缩短时间。
- 根启动器仅在根配置/资源缺失时引用原 worktree 路径；代价是默认继续使用原配置，直到创建根配置或显式传入 -ConfigDir。文件位置保持不变。
- 发布与真实服务验证由主执行者完成；代价是只有 Windows 与两页真实样例的证据范围，其他范围没有推断通过。

## 本地文件位置

每个所选工作区的 `.reader-workbench/document-memory/<hash>/` 保存分代记忆；`.reader-workbench/cache/<documentId>/<version>/` 保存源快照、页文本与页图像。对话与摘要沿用本地工作区存储。模型没有隐藏的持久记忆；后续请求由程序注入本地记忆，显式回看才附带页图像。
