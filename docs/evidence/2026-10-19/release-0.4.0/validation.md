# Reader Workbench 0.4.0 发布验证

日期：2026-10-19。版本为 0.4.0；SDK 协议仍为 1.2.0。新增功能与操作步骤见 [README](../../../../README.md#新版功能怎么用)。

## 发布范围

按范围首读与增量补读、可跳转的公式/图表/术语检索、文档及选区翻译、默认本地中英离线翻译、目录选择与统一菜单、主对话归档恢复、用户级 AI 配置和 Windows 双击启动器。保留原文、工作区历史与用户自定义插件；私有运行库和模型单独准备。

## 发布前修复

- 仅更新 API Key 时，所有已打开工作区的新请求使用新凭据，已有租约保留原 Provider；通过本地 HTTP 协议端点先复现旧 Key，再验证修复。
- Markdown 标准缩进代码不发送给翻译模型，也不读取其中的图片示例；真实图片按 Markdown 解析器规范识别，支持括号及空格路径并嵌入保存副本。
- 未修改的随包翻译插件从应用依赖树加载，支持工作区位于应用目录之外；自定义副本保持原路径，不覆盖用户修改。

## 实际边界

- 离线中英推理使用真实 CPU 引擎；安装器的部署验收仅覆盖 Windows x64。其他平台可选已配置的模型翻译，未将 Windows 部署结果推广为跨平台引擎部署结果。
- 常规交互与凭据更新测试使用本地协议模型，不调用用户的远程模型 API，也不证明专业术语翻译质量。
- PDF/PPT 输出原页与译文伴随页；扫描页不自动 OCR。Word 输出可编辑 DOCX，全文或选区可用，预览页裁分不可用，样式与分页可能改变。
- 译文预览缓冲保留至服务退出；单任务有大小限制，累计缓冲尚无全局上限。连续处理大型文件时应先另存，再重启服务释放缓冲。预览任务不跨服务重启保留。
- 无法识别的本地开发版或自定义翻译插件副本按用户文件保留，不擅自迁移其代码；需检查该副本实际版本与依赖。
- 物理麦克风、人工 OS 选择器和可选全局热键 helper 沿用独立验收边界。

运行日志、配置、密钥、数据库、模型、Python 字节码和本地 `Agents.md` 不进入 Git 或发行包。既有无关截图改动保留在工作树。
