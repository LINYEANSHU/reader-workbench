# 证据索引

每次完整验收使用日期目录。`manifest.json` 对 R01–R25 列出实际检查、命令、结果与证据哈希；`commands` 保存原始脱敏日志，`rendered` 保存自生成文档和生成阅读件的实际页面，`screenshots` 保存成品交互。

平台与验证方式分别标注：实际 Windows 结果、未运行 macOS/Linux、真实 LLM、协议测试模型、真实本地语音、浏览器音频重放、手动物理麦克风、自动选择的真实浏览器屏幕捕获及未测 OS 手工选择器。配置或测试样例不代替运行证据。

这里不保存 API Key、认证 token、私人配置目录、用户原文或用户录音。测试材料为项目自生成样例。
