# 证据索引

每次完整验收使用日期目录。`manifest.json` 对 R01–R25 列出实际检查、命令、结果与证据哈希；`rendered` 保存自生成文档和生成阅读件的实际页面，`screenshots` 保存成品交互。原始日志只保留在本地，并由 `.gitignore` 排除；历史 manifest 中的日志路径和哈希是本地验收记录，不保证在 GitHub 中提供对应文件。GitHub CI 的执行日志见仓库 Actions。

平台与验证方式分别标注：实际 Windows 结果、未运行 macOS/Linux、真实 LLM、协议测试模型、真实本地语音、浏览器音频重放、手动物理麦克风、自动选择的真实浏览器屏幕捕获及未测 OS 手工选择器。配置或测试样例不代替运行证据。

这里不保存 API Key、认证 token、私人配置目录、用户原文或用户录音。测试材料为项目自生成样例。
