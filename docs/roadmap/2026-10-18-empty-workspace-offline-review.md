# 本地审查：空对话、工作区恢复与离线翻译

日期：2026-10-18。分支：`codex/reading-controls-translation`。修改仅在本地，未提交、推送或发布。

## 可审查的行为

1. 归档所有主对话后，主对话与临时对话显示空状态，没有输入框，不创建替代对话；刷新仍为空。侧栏“新建主对话”或手动恢复归档后才恢复对话。首次使用全新工作区的初始对话行为保留。归档记录、历史及分支继续保留。
2. 已记住的工作目录在关机后被删除，重新启动不会重建它。插件与 MCP 启动恢复会跳过不可用目录，页面提示重新选择工作区。内部存储仅在已经存在且可访问的工作区内创建。
3. 一键翻译默认选择“本地离线翻译”，支持中英互译，无需配置聊天模型、翻译模型或 API Key。当前目录的私有 CPU 运行库已部署，约 309 MiB，包含独立 Python、CTranslate2、SentencePiece、OpenCC 与中英双向模型。推理不联网。仍可手动切换到“已配置的 AI 模型”。

译文经过预览后另存，不覆盖原文件。公式、代码、图片和来源定位沿用文档处理器保护。真实浏览器已完成英文原文→简体中文→打开另存文件→英文译文流程；混排注释、技术词边界及长文分批另有真实引擎测试。扫描页没有文本层时仍不自动 OCR；这是通用翻译引擎，专业术语可在预览中校对。

## 审查入口

重新运行根目录的 `Start-Reader.cmd` 或 `Start-Reader.ps1`，然后打开任一 Markdown / PDF / Office 文档并点击“一键翻译”。离线翻译与聊天模型配置相互独立。本轮没有停止已有的日常服务；已打开的旧服务需要重启以加载后端修改。
