# 阅读控件、首读范围、可检索记忆与翻译插件

用户于 2026-10-18 明确授权直接开发全部下列范围，并撤回等待额外 Skill 的条件；学习联动完全排除。沿用已讨论的准备稿作为依据，新增实现细节由开发判断解决，不重复请求阶段审批。

## 范围

1. 资源管理器式目录选择：双栏目录树/常用位置与目录列表、规范化地址/面包屑、前进后退、当前目录过滤、完整所选路径，正确处理 Windows 根目录与 POSIX。
2. 同一圆角弹出选择组件替换外观、模型、设置风格和临时分支的原生选单；三主题与键盘可用，弹层不可裁切；思考强度维持现状。
3. 导入/首次打开时可设置首读页数，支持全部、前 N 页、多段 `2-3,10-15`。规范化去重，显示真实页数，可在原文上补读。仅实际选定范围进入模型；本地预渲染也不默认遍历所有页。
4. PDF/PPT 视觉预读；Markdown/Word 文本预读，保留真实页/块来源。临时首问同样可建立记忆，选区操作可独立于全文预读。
5. 概览与细节分层，公式/图表/术语条目检索，结合编号、中文描述和来源范围，结果可跳原文。旧记忆兼容，不伪造几何位置，不把范围完成显示成全文完成。
6. 独立 bundled 翻译插件通过新增通用文档处理能力接入。配置中的模型负责按编号块返回译文；程序提供文本/几何，不让模型编造坐标。支持预览、进度、取消和明确保存，另存文件并保留原件。

## 翻译行为

- Markdown：结构化正文翻译，保护代码、公式、链接目标和图片引用，保存新 Markdown 后相对图片仍可用。
- Word：DOCX 保留可编辑段落、表格、图片和公式结构；旧 DOC 可通过已有 LibreOffice 转换副本处理，缺转换器明确报错。
- PDF/PPT：提取文本层及几何，保留原页背景与公式/图内小字。按源页排版译文并导出 PDF；译文过长必须有可见处理/警告，不静默截断。扫描无文本页明确不支持此翻译路径，不安装 OCR。
- 默认译为简体中文，提供目标语言选择；可翻译选区或指定页/全部正文。选区解释与翻译只发相关文字，不触发全篇视觉预读。
- 插件读取受控文档副本与宿主提供的模型，不能在用户工作区任意写入；预览在内部缓存，保存通过 ArtifactService 的授权/原子另存流程。

## 架构与边界

UI 包拥有目录浏览与选择组件；记忆包拥有阅读计划、契约、记忆插件、检索和记忆面板；翻译包拥有通用处理能力、服务、路由与插件；主代理负责入口接线、选页对话框、翻译对话框及整体测试。共享的 App、DocumentPane、Workbench、api/client、package.json、bundled 安装接线由主代理整合，避免并行覆盖。

所有文档操作按 workspace/document/version 隔离，所有处理任务按调用者和会话验证。复用既有 SQLite、PDF.js、pdf-lib、LibreOffice、fflate、fast-xml-parser；新依赖需有实际必要性。模型请求省略输出上限，遵守既有输入容量与用量记录。

当前工作区包含用户既有未提交改动；在新建的本地 codex/reading-controls-translation 分支原位开发，不重置或复制旧配置。不提交/推送本轮成果，除非用户后续要求。若推送，必须等待对应 SHA 的三平台全部必需检查成功。
