# 阅读界面参考与实测

参考来源为 [DeepSeek Harness 官方页面](https://deepseek.com/harness/)。2026-10-11 用 Chromium 实际打开页面并检查官方产品展示：深色对话区域、蓝灰工作区侧栏、紧凑路径栏、底部输入框与简单消息布局。

本应用采用相同的阅读工作台风格，使用自己的名称与图标。主要差异是文档、主对话、临时对话各有独立区域与输入框；文档使用白色页面和原版分页；临时对话用绿色提示区分，并说明不回写主记忆。模型连接与输出目录保存在当前工作区设置中，凭据由本地服务单独保存。

Task 9 的 Chromium 测试通过实际工作区、HTTP 模型协议测试服务及本地 LibreOffice 验证。测试模型名称明确为 `browser-protocol-test`，这些浏览器用例验证交互和协议，不作为真实 LLM 回答质量的证据；真实 DeepSeek 测试单独记录。

- Markdown：中文标题、GFM 表格、KaTeX 公式和授权本地图片可见，禁止执行原始 HTML 与危险链接。
- PDF / Word / PPT：检查对应文件 SHA-256 版本的实际 canvas 和 TextLayer，防止切换标签时误验上一文件；截图中中文、公式、表格、图片和原版页面可见。
- PDF 返回标签时恢复实际滚动位置。恢复发生在 PDF 页面占位布局建立后，加载期间的零位置不覆盖原来位置。
- 主对话和临时对话同时运行；临时请求的主记忆版本仅包含已完成轮次，独立思考档位进入实际 RunRecord。
- 临时清空和追问不改变主记录或主滚动；旧版来源引用仍打开原来的文档版本。
- 刷新接回持久化运行，不重新提交问题；页面离开时提交界面状态。

Task 9 暂为三列。布局自由排列、选字提问、截图和内置语音的验收属于后续专门任务，最终交付记录会给出完整结果。
